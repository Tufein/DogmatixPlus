# Dogmatix+ 2.1.0

Regular release; originally published as **v8.2.0-beta.2**. The preserved APK reports `8.2.0-beta.2` (Android build 33).

**Dogmatix+ 8.2.0 beta 2** — bulk-download stability fixes.

- Large selections and selected retries use the batch download path away from the UI thread. Storage-folder checks and queue controls also run in the background.
- Large waiting queues combine automatic updates to avoid repeatedly copying the full list as hundreds of downloads enter the queue.
- Torrent progress reads are shared by files from the same torrent. Native torrent lifecycle work no longer blocks the foreground service on the UI thread.
- Pausing or stopping an HTTP download now cancels its transfer loop even without a speed limit, so it cannot keep writing and then report completion.
- Rapid stop/pause and retry actions wait for the previous transfer and torrent cleanup before starting the replacement.
- Finished-file checks run one at a time to reduce competing reads on SD cards and storage providers.
- Download history is initialized before its background restore starts; background persistence errors are handled locally.
- Includes the verified library operations, recovery, play and version preferences introduced in beta 1. Updates use the established release signing key; database version stays 13.

Validation and the real-device bulk-download checklist are documented in `docs/quality/bulk-download-stability.md`. The screenshot alone does not identify a crash stack; these fixes address reproducible code paths without claiming that every device-specific crash is resolved.
