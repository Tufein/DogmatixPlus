**Dogmatix+ 3.3.0** — downloads that retry by themselves, a DAT check after every download, moving the library to the SD card, and a few tools around RomM, the wishlist and your frontends.

### Downloads
- **Failed downloads retry by themselves** (*Settings → Retry failed downloads by itself*, on by default) when the connection dropped, timed out or the server was busy: after 1, then 5, then 15 minutes, then it is left to you. A missing (404) or refused (403) file is not retried.
- **Checked against your DAT after the download** when the source publishes no checksum and you imported a DAT for that console: the row says *✓ matches the DAT* or *not in the DAT*.

### Storage
- **Move the library to another storage** (*Tools → Storage → Move the library*): every game is copied, checked against the original's size, and only then is the original deleted. A game that cannot be copied stays where it is. Stop your downloads first and keep Dogmatix open.

### RomM
- **Upload what the server lacks** (*Settings → RomM → Upload what the server lacks*): sends the finished downloads RomM does not list yet. Needs *Mark games already in RomM*.

### Wishlist and tools
- **Share the wishlist** as a small file (*Export* / *Import*).
- **Frontend check** (*Tools → Frontend check*): what is ready, still to do or manual for ES-DE, iiSU, Daijishō, Pegasus and RetroArch, with a tap through to Settings.

### Good to know
- Updating from 3.2.0 keeps everything; there is no database change.
- Checked by the unit tests and a debug build in CI. **None of this has been tried on a real device or a real RomM server yet.** *Move the library* and *Upload what the server lacks* touch your files, so try them on a small folder first, and please report anything odd as an issue.
- Not in this version: covers for iiSU and Daijishō, and save sync for DuckStation and PPSSPP. Both need real files from a device to build safely.
