**Dogmatix+ 2.7.0** — safer downloads, archives, saves and updates.

- **Safe archive extraction:** archive paths remain separated, unsafe paths and name collisions are rejected before anything is unpacked, and a failed destination or partial extraction is reported without deleting the original archive.
- **Multi-disc folders:** library ownership includes nested game folders; playlists and disc descriptors grant access to their safe child files when launching. Automatic playlists keep discs from separate folders apart.
- **Safe re-downloads:** a completed file stays available while a replacement is downloaded and verified. Interrupted transfers resume from their own staging file; the original bytes are protected by a verified recovery copy before replacement.
- **Recover interrupted replacements:** open **Tools → Files**, enter the affected folder and choose a verified recovery copy. A different current file is never overwritten. If a storage provider refuses both replacement and rollback, the original bytes remain in this recovery copy until you restore them.
- **Reliable save sync:** a local save is backed up and verified before a sync deletion or replacement. Backup errors stop that operation and keep the original save; safety copies use unique names and are checked before restore.
- **Complete backup validation:** settings are checked against the full schema and safe ranges before restore. Invalid values are skipped while the current setting remains intact.
- **Safer filenames:** URLs with folders, queries, encoded characters or literal `+` signs now resolve to a safe storage name while their source identity remains unchanged.
- **Reliable RomM upload checks:** missing game files fail before an upload starts. Games with folders require uploading their original archive because the current upload method cannot preserve their layout.
- **Protected in-app updates:** the APK checksum, package name, version and signing certificate are checked before Android’s installer is opened. Mismatched test keys now get a clear recovery message.
- **Updatable test APKs:** published debug APKs use a stable, separate signing key from 2.7.0 onward. Older debug releases used changing keys and cannot be updated in place: export your backup before a one-time test-build reinstall. Production release APKs retain the established signing key and update in place.
- All new interface text is available in the seven supported languages.

Android build **39**, database version **15**. Updating the production release keeps existing downloads, profiles, saves and settings. SHA-256 receipts apply to new save safety copies; legacy copies remain restorable.

Public versions continue **2.6.0 → 2.7.0** as a regular release. Install the signed release APK over 2.6.0 to retain application data.
