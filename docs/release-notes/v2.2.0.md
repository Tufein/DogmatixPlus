**Dogmatix+ 2.2.0** — clearer download progress and errors.

- Per-download transfer speed is smoothed, with remaining bytes and an estimated remaining time when the file size is known. Paused downloads and stalled transfers no longer show an old moving speed.
- Unknown-size downloads remain visible without pretending the whole queue has a reliable completion time.
- Download failures explain the next step for network, source/server, storage, permission and archive problems. Sensitive source URLs and raw server messages are not shown.
- The release sequence is now **1.0.0, 1.1.0, …, 1.9.0, 2.0.0**. All 12 historical releases were renumbered in publication order and are regular releases; original source references remain archived. This new release is **2.2.0**.
- Future update checks use the Android build number, avoiding confusion from renamed public versions. Android build **34**, existing package/signing identity and database version **13**.

**First upgrade from an older 8.x APK:** download and install `DogmatixPlus-release.apk` manually once. The old updater compares public labels and cannot automatically offer a lower label. This APK updates the existing app in place; future checks use the increasing build number.

Historical APKs keep their original embedded versions. See [the version mapping](https://github.com/Tufein/DogmatixPlus/blob/master/docs/releases/numbering.md) for details. Classified failure details apply to the current session; restored historical failures have generic recovery guidance.
