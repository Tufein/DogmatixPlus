# Dogmatix+ 1.2.0

Regular release; originally published as **v3.0.0**. The preserved APK reports `3.0.0` (Android build 20).

**Dogmatix+ 3.0.0** — downloads that continue where they stopped and a queue that survives a restart, covers for ES-DE, RetroAchievements badges, profiles with a PIN, and more.

### Downloads
- **Continue where it stopped.** A download cut off by a full storage, a closed app or a reboot carries on from what it already had when you retry, if the server allows it — and only if it is still the same file.
- **The queue survives a restart.** Downloads that were waiting or running when the app closed start again when you open Dogmatix+.
- **Per server**: choose how many downloads may run at once from one server, so a strict server does not block you.
- **Wishlist on autopilot**: when a wanted game turns up in a source, its best version is downloaded straight away (*Settings*).
- **Playlists for multi-disc games** are made as soon as the last disc is in.
- **"Download everything shown"** now shows where the space goes per console, how much is missing, and how much removing duplicate games would free.

### Library
- **Covers for ES-DE**: after a download, the box art and description go where ES-DE (and Cocoon's ES-DE link) look for them. Box art comes from libretro-thumbnails, which needs no account.
- **RetroAchievements**: add your RA name and web API key in *Library tools → RetroAchievements* and see which of your games have achievements — an **RA** badge in the library and the count in the details.
- **Profiles**: hide consoles or games with certain tags, for a child or a couch profile. With a PIN, only you can leave a restricted profile.
- **What you play**: *Statistics* shows the games ES-DE started most and most recently.

### Good to know
- Updating from 2.6.0 keeps everything; there is no database change.
- Tested on an emulator against a local test server: resuming after a force-stop (the file's checksum matched), the queue after a restart, the per-server limit, the wishlist download, `.m3u` playlists, ES-DE covers (real box art from libretro-thumbnails), profiles with a wrong and a right PIN, and play counts from ES-DE.
- **RetroAchievements was not tried with a real account** — that needs your own key. The hashing rules and the reading of RA's game list are covered by unit tests.
- Cocoon keeps play time in its own private database, so Dogmatix+ shows ES-DE's play counts instead.
