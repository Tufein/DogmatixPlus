**Pre-release.** Version **1.1.0-beta.1** of DogmatixPlus. Its main new feature is **save sync with RomM**, plus favourites sync from the roadmap.

### What is new
- **Save sync with RomM** (*Settings → Save sync*): your RomM server keeps your **game saves and save states**. Pick the folders your emulator saves into (for RetroArch: `RetroArch/saves` and `RetroArch/states`). DogmatixPlus sends new progress to the server and fetches newer progress from another handheld or from RomM's web player.
  - Only the side that changed is copied. If a save changed **on both sides**, nothing is overwritten: you choose *◀ Device* or *RomM ▶*.
  - Before a download replaces a file on your device, the old copy is kept for 30 days in the app's private storage.
  - *Sync now*, or switch on *Sync automatically*: then it syncs when the app opens and when you come back to it from a game.
  - A save belongs to the RomM game with the same file name (`Pokemon Emerald (USA).srm` ↔ `Pokemon Emerald (USA).gba`).
  - Tested against RomM **3.10.3, 4.0.0 and 5.3.1**. Log in with an `rmm_…` API token (scopes: assets read/write, roms read) or with `user:password`.
- **Favourites sync**: *Sources → Export* now also saves your ★ favourites. Importing that file on another device adds them there.

### Please read before installing
- **This is a beta.** The sync logic is covered by automatic tests, and one of them runs two simulated devices against real RomM servers. The new screen has **not** been tried on a real handheld or an emulator yet. Make a copy of your saves folder before the first sync.
- **Close the game before you sync.** An emulator that is still running can write its older save over a freshly downloaded one.
- **Deleting a save is not synced.** A save you delete on one side comes back from the other side.
- **This build is signed with a different key than 1.0.0**, so Android will not install it as an update. Make a backup in 1.0.0 (*Settings → Back up*), uninstall it, install this version and restore the backup. `DogmatixPlus-debug.apk` installs next to the official Dogmatix, as before.
- The in-app update check skips pre-releases, so 1.0.0 users are not pointed here.
