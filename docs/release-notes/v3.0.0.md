# Dogmatix+ 3.0.0 — plan what to play, repair your library, report a problem

This is the 3.0.0 release. It adds three things aimed at people who use Dogmatix+ every day on a handheld: a personal play list, a guided library repair and a private way to report a problem. Android build 42; database version 15 is unchanged, so no data is migrated.

## Up next and For you

Open **Tools → Up next**, or look at the new **Up next** shelf under *Continue playing* on the Library screen. Every game page has an **Add to Up next** button. The list is personal to the active profile: reorder games, mark them as playing or finished, play or download them from the list, and clear the finished ones. Nothing happens to the game files when a game leaves the list.

The **For you** tab suggests games from your own library. Each suggestion says why it is there, for example "Because you played …", "Same series as …", or "Among the most played on RetroAchievements for …". The suggestions are computed on the device from your favourites, play history, downloads, collections, game details that were already fetched and saved RetroAchievements lists. They are not recommendations from a server and nothing is sent anywhere. With little data the list is short instead of padded.

## Library repair

**Tools → Library repair** reads your game folders and lists problems sorted by how much they matter: files that stop a game (empty or cut-off files, disc sheets whose track files are missing, playlists that name discs which are gone), things worth a look (tracks without a disc sheet, partial files from other apps, a library entry whose size no longer matches the file) and tidy-ups (leftover data of interrupted downloads, duplicate playlists, a missing playlist for a multi-disc game, library marks that are out of date).

Every item explains the problem and shows what a fix would do before anything changes. Files that are removed go to **Trash and recovery** with the same verified copy and journal as other removals, so they can be restored. "Fix safe items" only adds playlists and refreshes library marks; it never removes, replaces or downloads anything. If the files changed after the check, the fix is refused and you are asked to check again. The scan is bounded, can be cancelled, tells you when a folder could not be read completely, and respects the active profile. The result can be shared as a plain-text report.

## Report a problem

**Settings → App and updates → Report a problem** (and **Tools → Report a problem**) prepares a report you can paste into a GitHub issue or a Reddit post. You choose the sections (app version, device, language and text size, storage space, a settings summary, integrations, counts, health checks, recent history and the last crash), read the result, edit it and copy or share it. Paths, folder document ids, server addresses, host names, tokens and long keys are removed before the text is shown, and a summary says what will be shared. The app starts no network request for this; the sharing sheet is Android's.

## Controls, translations and compatibility

All three screens support the controller (D-pad focus, A and B, button legend) and touch, large text and light/dark themes, and are translated into the seven interface languages. The new screens are searchable. The database stays at version 15; the signed production APK updates 2.9.0 in place, and the separately signed test APK follows the stable test key used since 2.7.0.

## What this release does not claim

This release was built and unit-tested without a physical handheld. The launch checks on a real AYN Thor (Android 13) — both displays, the physical controller, sleep and resume, SD-card interruptions, accessibility — have no recorded results yet. Neither has any live RomM or WebDAV server: the owner has no RomM installation, and protocol fixtures do not replace that test. The new screens were exercised by unit tests and the CI emulator suite, not by a person on a device. The [acceptance record](https://github.com/Tufein/DogmatixPlus/blob/master/docs/quality/v3.0.0-acceptance.md) lists what was and was not checked. The community draft for Reddit has not been posted.
