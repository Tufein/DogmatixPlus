**Dogmatix+ 2.3.0** — easier bulk download management and safer transfers.

- **Find downloads:** search by title or file name and filter active, waiting, paused, problem and completed rows. The queue summary still covers the whole queue.
- **Act on matching rows:** select the visible results for batch actions. Changing the search or filter clears the selection so hidden rows are not affected.
- **Batch priority:** move selected waiting downloads to the front together, preserving their existing relative order and per-server limits. Transfers already running continue.
- **Safer HTTP resuming:** malformed or mismatched partial responses cannot overwrite a partial file with the wrong tail. A fresh request is used when the server cannot continue safely. Bodies shorter or longer than an exact server-announced length fail before completion or archive extraction. Rounded catalog sizes remain supported.
- **Reliable automatic retry:** timers from an earlier attempt are cancelled after manual retry, stop or deletion. Disabling automatic retry prevents a scheduled attempt from starting.
- Revoking notification permission during a transfer no longer lets completion or low-space notifications crash the app.
- Cancelling a torrent while metadata is being fetched now releases its unowned native handle without deleting cached files used by other downloads.
- Android build **35**, database version **13**, established application ID and signing identity.

Updates from 2.2.0 work through the app. From older 8.x APKs, install `DogmatixPlus-release.apk` manually once to cross the public version rename.

Automated checks cover queue ordering, filters and selection, retry races, and real local HTTP response scenarios on Android. Physical handhelds and live download sources still need device testing.
