# Dogmatix+ 1.9.0

Regular release; originally published as **v8.1.0**. The preserved APK reports `8.1.0` (Android build 31).

**Dogmatix+ 8.1.0** — tidier, pure black Settings.

### Changed
- **Pure black (AMOLED) Settings**: with a dark or True black theme, Settings, RomM and Save sync sit on real black, with black cards and a thin outline instead of grey panels. No background glow there. The light theme stays light.
- **Symmetric and tidy**: equal margins left and right, a centred column, the same padding in every card, rows side by side always the same height, icons and switches/steppers each on one line, and every stepper the same width.
- **Small screens** (like the Thor's bottom screen) show one centred column instead of two cramped ones.

### Good to know
- Texts in Settings are still never cut off; long ones wrap.
- Updating from 8.0.0 keeps everything. The database does not change.
- Checked by the unit tests, layout screenshots and a debug and release build in CI. **Not tried on a real device yet.**

Full list of changes: `CHANGELOG.md`.
