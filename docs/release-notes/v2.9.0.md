# Dogmatix+ 2.9.0 — package recovery and large-library preparation

This release adds a way to keep the relationships between a game's discs, tracks and folders through a reinstall or a new device. It also reduces database work when preparing offline collections. Android build 41; database version 15 is unchanged.

## Package records you can carry with you

Open **Tools → Game package records** to export the latest recorded file list and checksums for each game source. Export is read back before success is reported. The document contains no folder permissions, raw download credentials, game files or save bytes.

On the receiving installation, copy the game folders separately, select the game folders again and scan the same sources. Open the export and check one configured folder at a time. Only complete packages matching their original source, file sizes and SHA-256 hashes can be restored; the confirmation shows the eligible game/file count. Other packages remain unchanged, and the document stays open so you can check another folder.

Existing different or corrupt records are protected. Files changed after the preview, an unavailable folder or a changed profile block stale restoration. Import never copies, overwrites, moves or deletes game/save bytes. See the [reinstall and device-change guide](https://github.com/Tufein/DogmatixPlus/blob/master/docs/guides/package-recovery.md) for the full procedure and transfer limits.

## Less database work for offline collections

Collection preparation now matches only collection/review games and reads tags in bounded groups, retaining every matching source row. It avoids a separate tag query for every game in an entire console library. A reproducible synthetic 10,000/50,000-row Android benchmark checks search pages, collection pages, exact package matches and queue summaries. Emulator timings are recorded in the [launch test matrix](https://github.com/Tufein/DogmatixPlus/blob/master/docs/quality/community-launch-matrix.md); they are not handheld performance claims.

## Controls, translations and testing

The new screen is searchable, has seven translations and waits for loaded actions before giving controller focus. Package confirmation and file-list dialogs support controller B/back cancellation. Regression tests cover wrong roots, same-size file mutations, source mismatches, restrictions, failed readback, existing-record conflicts, idempotent restoration and registration write failures. Full candidate build/UI/update results are recorded in the [acceptance record](https://github.com/Tufein/DogmatixPlus/blob/master/docs/quality/v2.9.0-acceptance.md).

Portrait navigation now grows with its labels instead of clipping long translations at large text sizes. A narrow French layout at 160% text size checks that every full label fits inside its clickable button.

## Updates and remaining launch checks

The signed production APK updates 2.8.0 in place. The separately signed test APK follows the stable test key used since 2.7.0. Older test APKs with changing signing keys still require a one-time backup and reinstall. Keep a general app backup, a package-record export and separate game/save copies before a reinstall; they serve different purposes.

The requested target is AYN Thor running Android 13. Physical controller, two-display, sleep and SD-card interruption checks still need actual device results. The owner has no RomM installation yet; no live RomM/WebDAV server is certified by this release. Protocol/provider fixtures and emulators do not replace those tests. Full multi-file NAS/RomM upload remains future work.

Public numbering continues **2.8.0 → 2.9.0 → 3.0.0**. The wider Reddit launch remains the 3.0.0 milestone. The community draft has not been posted.
