**Dogmatix+ 2.4.0** — emulator choices, clearer version preferences and readable action history.

- Choose an installed compatible emulator per console in Settings. Known emulators use their launch recipes; other binary-file handlers remain available. Installed application variants can be selected individually.
- Start owned games without downloading again. Launch planning includes shared disc/playlist dependencies while removal continues to protect files used by another game.
- Compare game versions by language, region, revision, edition and filename dump markers. Markers in a name remain claims; completed DAT/RetroAchievements checks are shown separately.
- Save global and per-console version rules or a fixed version per game. Automatic wishlist, import, bulk, best-games and duplicate suggestions respect those choices when the file is present; missing preferences fall back safely.
- A searchable action history groups downloads, moves, removals, playing, synchronization and version choices. Restore recovery copies or queue another download when allowed by the current profile.
- History restore refreshes owned-game state. Failed history writes or clears report failure rather than showing a false success. Restore retains recovery copies when storage is unavailable or conflicts.
- New interface text is available in all seven supported languages, with controller focus and large-text layouts.
- Android build **36**, database version **13**, established application ID and release signing certificate.

The new public numbering continues **2.3.0 → 2.4.0**. Historical 8.x names are archived; install the current signed APK manually once when upgrading from legacy 8.x builds. From 2.2.0 onward update checks use the Android build number.

Recovery trash consumes space until it is emptied. The general file explorer still deletes permanently. Supported emulator recipes do not certify every emulator build or device; physical removable storage, controllers and real RomM/WebDAV interoperability need separate device testing.
