# Dogmatix+ 1.0.0

First regular release. Preserved APK version `1.0.0`, Android build 12.

Unofficial build based on **Dogmatix 1.2** by [cortinadev](https://github.com/cortinadev/dogmatix) (itself a fork of [Milou](https://github.com/santiifm/milou) by santiifm). The app shows version **1.0.0**; the Credits screen lists the whole lineage. Source: this repository at commit `0ad2c63`.

### What is new compared to Dogmatix 1.2
- **Duplicate games**: finds games that are on disk more than once and deletes the copy you pick after a confirmation that lists every file it removes. It is built to report too little rather than too much.
- **Library overview**: per console what the scan found, what you own and what is on disk, with a per-console or full rescan.
- **Backup & restore**: settings, sources, favourites and the downloads list in one file (it contains your API keys, keep it private).
- **Scan progress**: percentage, sources done and estimated time left.
- **Dutch, French and German** next to English and Spanish (Settings -> Language).

### Which file?
| File | Package | For |
|---|---|---|
| `DogmatixPlus-debug.apk` | `com.cortinadev.dogmatix.debug` | Trying it out. Installs **next to** the official Dogmatix and keeps its data separate. |
| `DogmatixPlus-release.apk` | `com.cortinadev.dogmatix` | Smaller (minified). Signed with a debug key, **not** the official one, so Android will not install it over the official app: uninstall that first (make a backup before). Updates from the original developer cannot be installed over it. |

Both are version code 12, so they update the first upload of this release (version code 11, which showed "1.2") in place.
