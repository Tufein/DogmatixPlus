**Dogmatix+ 1.3.0** — fewer scan errors with busy servers, a scan report, and a file explorer.

### What is new
- **Fewer scan errors.** Since 1.2.0 sources are scanned side by side, and some servers (for example with large Nintendo Switch sets) answered "too many requests" or "busy" — those sources then failed. Dogmatix+ now waits as long as the server asks and tries again (up to five times), slows down for a server that pushes back, does not retry pages that do not exist, and gives a slow torrent a second chance.
- **Scan report.** Instead of one error after another, you get one overview at the end of a scan: which sources failed and why, with **Scan these again** to retry just those.
- **Status per source.** In *Sources*, every URL shows how many games its last scan found and when — or why it failed.
- **File explorer** (*Settings → Library tools → File explorer*): look inside your download folder, the per-console folders, the save folders and the ES-DE folder. Sort by name or size, add up the size of a folder, check its disc sets, see which files count as games, open a file in another app or delete it.

### Good to know
- Updating from 1.2.0 works as a normal update. Coming from an older DogmatixPlus (before 1.2.0)? That is a separate app: back up there, restore in Dogmatix+ (see the 1.2.0 notes).
- If a source still fails, the reason in the report tells you what to do: *not found* means the address changed, *access refused* often means a bot check on the website, *server asked to slow down* usually works when you scan those again a little later.
