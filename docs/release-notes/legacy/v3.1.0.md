**Dogmatix+ 3.1.0** — big download queues stay smooth again, whole-queue buttons, pausing web downloads, a notification when the queue is done, and save sync for standalone emulators.

### Fixed
- **"App isn't responding" with a big queue.** After the app closed with hundreds of downloads waiting, 3.0.0 put them back one by one while the first screen was drawing; Android closed the app, and the next start did the same. The queue now comes back in one go, in the background.
- **Smoother while downloading.** The download list and the rest of the app no longer redraw for every download every second.
- A download that was already complete when the app closed failed on every retry (`HTTP 416`); it now starts over.

### Downloads
- **Whole-queue buttons**: *Stop all*, *Retry failed* and *Clear finished* (the files stay), each with the number of downloads it acts on.
- **Pause web downloads**, running or still waiting — until now only torrents could pause. *Resume* continues from what was already downloaded.
- **A notification when the queue is done**: how many downloads went through and how many failed; tap it to open Downloads (*Settings*, on by default).

### Save sync
- **Standalone emulators**: *Save sync → Add an emulator's saves folder* syncs the in-game saves of DraStic, melonDS, mGBA, Pizza Boy GBA / GBC, GBA.emu, GBC.emu, Snes9x EX+, NES.emu and MD.emu with RomM, next to RetroArch. Save states of these emulators are not synced.

### Good to know
- Updating from 3.0.0 keeps everything; there is no database change. A profile PIN set in 3.0.0 keeps working (new PINs are stored more safely).
- Checked with the unit tests (348) and a debug and release build. **Not yet tried on a real device or against a RomM server** — the queue fixes, the buttons, the notification and the emulator folders are new in this release; please report anything odd as an issue.
