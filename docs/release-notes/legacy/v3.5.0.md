**Dogmatix+ 3.5.0** — whole console sets without "app isn't responding", tidy settings, and a few things for big queues.

### Big batches
- **No more "app isn't responding" after queueing a whole console.** Every finished download made the library look up *all* finished downloads again in the database; with thousands of games that kept the phone busy long after the batch, and again after a restart. Each download is now handled once, and the Downloads list loads its details in batches in the background.
- **Download all takes a whole console set**: up to 3000 games per tap (was 500). The dialog still shows the number of games and the space they need first.
- **Hold the queue** (*Downloads → Hold the queue*): running downloads finish, nothing new starts until you resume it. The hold stays after a restart.
- **Time left**: the line above the Downloads list shows how much is still to fetch and roughly how long that takes at the current speed.

### Tidier app
- **Settings in groups** (look and controls, downloads, when to download, after a download, torrents and debrid, library, frontends, RomM and saves, profiles, backup, app), with *Tools* as the first row. In portrait LB / RB jump between groups.
- **Tools in groups** too (library, games and checks, frontends, export). *Library overview* and *Duplicates* are only in Tools now.
- **What's new**: after an update the highlights of the new version are shown once.

### Good to know
- Updating from 3.3.0 keeps everything; there is no database change.
- Checked by the unit tests and a debug build in CI. **Not tried on a real device yet**, so the ANR fix is based on the code, not on a trace from your handheld. If a big batch still stalls, a diagnostics report (*Settings → Diagnostics*) helps.
