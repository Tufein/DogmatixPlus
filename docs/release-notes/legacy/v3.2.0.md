**Dogmatix+ 3.2.0** — the wishlist knows what you already have, and covers for Pegasus and RetroArch.

### Wishlist
- **Already have it?** A wanted game that is already on the device or on your RomM server now says so, with a *Have* or *RomM* badge, instead of "Not in the library yet". Such a game is not announced or downloaded automatically when a source lists it.

### Covers for more frontends
- **Pegasus** (*Settings → Covers for Pegasus*): after a download the cover goes to `media/<game>/boxFront` next to the game, where Pegasus looks when the console's `metadata.pegasus.txt` is in that folder.
- **RetroArch** (*Settings → Covers for RetroArch*): pick RetroArch's `thumbnails` folder once; after a download the box art goes where RetroArch's playlists look for it (`Nintendo - Game Boy Advance/Named_Boxarts/…png`), straight from libretro-thumbnails.
- Covers that are already there are never replaced.

### Good to know
- Updating from 3.1.0 keeps everything; there is no database change. Both cover options are off until you switch them on.
- The wishlist counts RomM games when *Mark games already in RomM* is on (the default once RomM is set up).
- Checked with the unit tests (353) and a debug and release build. **Not yet tried on a real device**, with Pegasus or with RetroArch — please report anything odd as an issue.
