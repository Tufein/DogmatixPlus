**Pre-release (alpha).** Version **1.2.0-alpha.1** of DogmatixPlus: a big batch of new features for RomM, save sync, the library tools and downloads. Expect rough edges and read the notes below before trusting it with data you cannot replace.

### What is new
- **RomM**: games that are already on your server get a **RomM** tag in the library · **self-signed HTTPS** works (check the certificate once, confirm its fingerprint, done) · interrupted **uploads resume** where they stopped · **covers for ES-DE** from RomM.
- **Save sync**: runs **in the background** every few hours (with a notification only when a save needs your choice) · optional **sync of deletions** with safeguards · conflicts show both times, both sizes and which copy looks newer.
- **Library tools** (*Settings → Library tools*): **game sets** (broken `.cue` / `.gdi` / `.m3u` and one-tap `.m3u` playlists for multi-disc games) · **storage** (space per console, biggest games, does the queue fit) · **wishlist** with a notification when a game turns up · **export** as CSV or web page · the duplicate finder now **suggests which copy to keep**.
- **Downloads**: **only on Wi-Fi / only while charging / only at night** · **checksum check** against the hash the source publishes · **Best version** in the game details · **Open** a finished download in an emulator.
- **Handheld**: **◀ ▶ jump by first letter** in the library.
- **Project**: **pre-releases in the update check** · **share diagnostics** for bug reports (tokens and server addresses removed) · **Italian and Portuguese**.

### Please read before installing
- **This is an alpha.** The logic is covered by 260 automatic tests and the screens were tried on an emulator (an upgrade from 1.0.0, the new tools screens, creating a playlist, the letter jump), but a lot has **not been tried against a real RomM server or on a real handheld**: the certificate trust, resumed uploads, deletion sync, background sync over a day, covers, the schedule (Wi-Fi / charger / night) and the checksum check. Make a copy of your saves folder before you switch on *Sync deletions*.
- **Install it as an update of 1.1.0-beta.1.** Both are signed with the same key, so Android installs it over the beta. From **1.0.0** you must make a backup, uninstall and restore once (its key was a different one). `DogmatixPlus-debug.apk` installs next to the official Dogmatix, as before.
- **Sync deletions is off by default.** It only deletes where the other side is exactly as the last sync left it, backs the device file up first, and holds back anything beyond a few deletions until you confirm; still, switch it on only once you trust your sync.
- **Notifications:** Android 13 and later asks for permission when you switch on background sync (and the wishlist notification needs it too).
- The update check skips pre-releases unless you switch on *Settings → Include pre-releases*.
