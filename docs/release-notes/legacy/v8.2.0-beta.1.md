**Dogmatix+ 8.2.0 beta 1** — safer library operations, recovery, playing and clearer version choices.

- Copies are checked by content before originals are removed. Conflicting destination files are preserved.
- Library moves copy the whole batch before switching folders; interrupted moves can be resumed from **Tools → Trash and recovery**.
- Game removal shows the exact files and protects saves and metadata. Game-page, duplicate, free-space and Downloads removal keep recovery copies.
- Recovery copies consume space until you empty trash; the general file explorer still deletes permanently.
- **Trash and recovery** lists copies and space used, restores original paths, and offers confirmed permanent deletion. Automatic expiry is optional and off by default.
- **Play** on an owned game's page opens a compatible application, with a remembered choice per console. Download again remains a secondary action.
- Version rows explain language, region, revision and dump warnings. A preferred version can be fixed for automatic wishlist, list import and bulk selection.
- The action history records moves, downloads and cloud sync outcomes; its shareable report excludes private paths and addresses.
- New texts are available in all seven supported languages.
- Public release builds require the established signing key; new lint errors and Android integration test failures block release.

This is a beta. See `docs/quality/recovery-acceptance.md` for automated coverage and the separate real-device and real-server checklist. Automated test success does not certify every storage provider or emulator.
