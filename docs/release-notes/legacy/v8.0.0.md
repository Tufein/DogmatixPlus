**Dogmatix+ 8.0.0** — a page for every game, a quick menu on the controller, smart storage for the SD card, one search for everything, and a TV mode. Builds on 7.5.0.

### New
- **A page for every game**: A or a tap on a game in the library opens a full-screen page with its art, a big **Download** button, and buttons for the best version, favourite, collections, share and remove (after a confirmation). Tabs: **About**, **Versions**, **Progress** (achievements and cloud saves) and **More like this**; LB / RB switch tabs. X or a long press still opens the quick details card.
- **Quick menu**: hold **SELECT** for a ring with Search, Search everything, Surprise me, Downloads, Pause all / Resume all, Tools and Settings. Choose with the stick or D-pad, let go (or press A) to open. A short SELECT press still marks a favourite.
- **Smart storage** (optional, off by default, *Tools → Storage*): consoles you have not played lately and have no favourites in move as a whole folder to a folder you pick on the SD card, and come back when you play them again. Every file is copied and checked before the original is deleted. *Check* shows what would move first; the weekly run only happens while charging. ES-DE is pointed to the new folder for you (restart ES-DE); other launchers need to be pointed there by hand.
- **Search everything**: one search for settings, tools, screens and your games. Open it from the quick menu, the Tools title or *Settings → Search settings and tools*; a setting you pick is scrolled into view and lit up.
- **TV mode** (*Settings → Look and controls*, Auto / On / Off): larger text and rows, margins so nothing falls off the TV's edges, and remote keys (channel and page keys switch sections). The app also shows up in the Android TV launcher with its own banner.

### Polish
- **Settings text is never cut off** any more: titles, hints and values wrap in full.
- A in the library no longer downloads straight away; the download button is on the game page.

### Good to know
- Updating from 7.5.0 keeps everything. The database does not change.
- Checked by the unit tests and a debug and release build in CI. **Not tried on a real device, a TV or an SD card yet.** Try *Smart storage* with *Check* first and look at what it would move before you press *Move now* or turn on the weekly run.
