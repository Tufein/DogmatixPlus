**Dogmatix+ 1.2.0** — the first full release since 1.0.0. It brings everything from the 1.1.0 beta and the 1.2.0 alpha, plus faster scanning, a new name and more colours.

### What is new in 1.2.0
- **Much faster scanning**: sources are scanned side by side instead of one by one, the fixed one-second pauses are gone, torrent metadata is remembered between rescans, and the library is written in one go per source. In a test with 6 large web directories (24,000 games) a full rescan went from 83 to about 21 seconds.
- **New name and package**: the app is now called **Dogmatix+** and has its own package name (`com.tufein.dogmatixplus`).
- **More colours**: 12 accent colours, and **Material You** on Android 12 and later (the colours follow your wallpaper).

### Also in this release (from the 1.1.0 beta and the 1.2.0 alpha)
- **Save sync with RomM** — in the background too, with optional sync of deletions.
- **RomM**: games already on your server are marked, self-signed HTTPS works, uploads resume, cover art for ES-DE.
- **Library tools**: game-set checks and `.m3u` playlists, storage overview, wishlist, export as CSV or web page, a suggestion which duplicate to keep.
- **Downloads**: only on Wi-Fi / while charging / at night, checksum check, *Best version*, *Open*.
- **◀ ▶ letter jump**, pre-releases in the update check, diagnostics for bug reports, **Italian and Portuguese**, favourites in the sources export.

### Please read before installing
- **Dogmatix+ installs as a new app.** Because the package name changed, it does not replace an older DogmatixPlus (or the official Dogmatix); both stay on your device. To take your settings, sources, favourites and downloads list along: in the old app *Settings → Back up*, then in Dogmatix+ *Settings → Restore backup*. Pick your folders again when asked, run the ES-DE / iiSU / Daijishō setup once more, and remove the old app when you are happy.
- `DogmatixPlus-release.apk` is the normal choice now; `DogmatixPlus-debug.apk` is a debug build that also installs next to everything else.
- **What has not been tried yet**: the RomM features (certificate trust, resumed uploads, sync of deletions, background sync, covers), the download schedule and the checksum check were covered by automatic tests and tried on an emulator, not against a real RomM server or on a real handheld. Make a copy of your saves folder before you switch on *Sync deletions*.
