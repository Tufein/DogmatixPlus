**Dogmatix+ 6.0.0** — find games by feel, see how complete your collection is, download when it suits you, share with the family, and a report that checks the whole app. Nothing about the layout or the buttons changed.

### Search by feel
- Filters for **genre and decade**, built from the game information you already have.
- **More like this** in the details card, and **Surprise me** on the controller's Start button.
- **Compact lists** in *Settings → Look and controls*.

### Your collection
- **Collection goals** (*Tools*): how complete each console is. The missing titles can go straight to *Import a list*.
- **Play history** (*Tools*): what you downloaded and played, day by day.

### Sharing
- **Share a game** as a card with its cover; share the **wishlist** as text.
- A **Continue playing** widget for the home screen.
- A wanted game that appears on your **RomM server** is announced with a notification.

### Download when it suits
- Per game, from the details card or the Downloads list: **only on Wi-Fi, while charging, tonight, or at a set time**.

### Your own cloud
- A **shared wishlist for the family** on your WebDAV server, with who added and who found each game.
- **Safer WebDAV sync and backup**: files are written in one piece, a newer version on the server is never overwritten, backups rotate by name, a warning for addresses without encryption, and cloud-save restore says which file it will replace.

### Check everything
- *Tools → Check everything*: one report on sources, storage, BIOS, RomM, backups, notifications and battery, with a button that fixes or opens the right screen.

### Good to know
- Updating from 5.0.0 keeps everything. The database does not change.
- Checked by the unit tests and a debug and release build in CI. **Not tried on a real device, nor against a real RomM or WebDAV server yet.** Try the shared wishlist with a test folder first. A diagnostics report (*Settings → Diagnostics*) helps if something does not connect.
