**Dogmatix+ 2.8.0** — more content choices and connected recovery, offline play and save workflows.

- **More romsets:** Sources now has an optional, searchable Libretro-content catalog covering 23 systems, including homebrew, demos and test content. Select collections and add them without replacing personal sources, names or disabled entries. The 134 files counted on 10 October 2026 are dated directory entries, not complete commercial ROM sets or a distinct game count. A fresh scan reads current availability; h5ai source sizes are parsed correctly.
- **Durable game packages:** downloads record the complete verified file set, including extracted discs and subfolders. Source, console and selected-folder identities remain isolated across restart; verified library and SD moves copy the package receipt before switching folders. Package receipts do not authorize broader deletion of shared files. General backups do not yet export package receipts or game bytes; that workflow is planned in 2.9.0.
- **Ready for offline play:** check an offline collection for readable game files, complete discs/tracks, BIOS and installed emulator choices. Missing items have links to the relevant repair screen; profile restrictions remain in force.
- **One recovery center:** preview trash restoration, interrupted moves, interrupted replacement copies and save safety copies from Tools → Recovery. Existing newer files and failed verification remain protected.
- **Storage reconnect:** selected folders have an explicit availability check. A missing folder parks its interruptible downloads while keeping partial bytes; resuming requires a successful create/write/read check and an explicit action. Returning storage does not trigger an automatic replacement or restore.
- **Personal game journal:** keep notes and selected screenshots/PDF manuals per game and profile. Notes and attachment metadata travel in backups. Attachments restored without local access require selecting the document again.
- **Guided device handoff:** inspect and upload ordinary saves for a game before continuing on another device. Conflicts, changed preview data and failed verification prevent a ready result. Save-state compatibility is not assumed. Guided handoff accepts ordinary saves up to 16 MiB per file; use ordinary save sync for larger files.
- All new interface text is available in the seven supported languages.

Android build **40**, database version **15**. The production release updates 2.7.0 in place. Debug APKs retain their separate stable key introduced in 2.7.0; older debug APKs require exporting a backup before their one-time reinstall.

The Reddit community launch is a later milestone; a passing emulator suite does not claim physical SD-card or server validation.
