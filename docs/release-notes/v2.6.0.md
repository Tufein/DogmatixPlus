**Dogmatix+ 2.6.0** — download recovery, saved presets, shared plans and an emulator choice for each game.

- **Automatic retry countdown:** failed downloads show when the next attempt starts and which attempt it is. Choose **Try now** or **Cancel retry**. Pausing, stopping, removing, changing source or starting a newer attempt cancels the old timer.
- **Remembered download errors:** the failure category, HTTP status when applicable and failure time survive an app restart. Retrying clears the previous failure. Stored feedback excludes raw exception text and source credentials.
- **Download presets:** open **Settings → Downloads → Download presets** to apply or edit daytime/nighttime presets, save your current speed/concurrency/scheduling settings as a named preset, or remove a custom preset.
- **Choose another source:** open **Change source** on a queued, active, paused, failed or stopped download. Review an exact matching file from an enabled source and confirm the restart. The previous transfer and cleanup finish before the replacement begins; partial data from another source is discarded.
- **Share a download plan:** export or share selected eligible Downloads rows, or the eligible queue, and import the JSON plan on another handheld. Review available, missing, restricted, already queued and already owned files before confirming. Selection order and per-item conditions travel with the plan; each receiver uses its own sources, folders, credentials and global settings. Active transfers and file extraction/copying are excluded from export.
- **Emulator per game:** save an installed emulator variant/core from a game page, separately from the console default. Choices belong to the active profile and are included in backups. Game launch and **Ready to play?** use the same effective choice; reset a game to its console default when desired.
- All new interface text is available in the seven supported languages, with controller-friendly dialogs.
- Android build **38**, database version **15**. Migration retains existing download history and profile data. Application ID and release signing certificate remain established for an in-place update.

Public versions continue **2.5.0 → 2.6.0** as a regular release. Install the signed release APK over 2.5.0 to retain application data.

A shared plan contains game/file identifiers and conditions, not game files. The receiving device must have matching indexed files from its own enabled sources. A manual source change restarts that file and can require downloading its bytes again.
