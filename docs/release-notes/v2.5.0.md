**Dogmatix+ 2.5.0** — a BIOS check, ROM patching, links shared straight to the app, a download queue you can reorder, saved views, statistics, RomM collections, Redump DATs, a second screen and automatic backups.

### Emulators
- **BIOS check** (*Library tools → BIOS check*): pick your emulator's BIOS folder and see per console whether the files it needs are there and are the right dumps. About twenty systems, from PlayStation and Saturn to Dreamcast, DS and Neo Geo.
- **Apply a patch** (*File explorer → a game → Apply patch*): IPS, UPS and BPS fan translations and hacks. The result is a new copy next to the game; the original stays as it was. A patch made for another dump of the game is refused instead of producing a game that does not start.
- **Second screen**: on a dual-screen handheld or with a TV connected, the second display shows the game you are on (cover, title, description) and your downloads. It can be turned off in *Settings*.

### Downloads
- **Share links to the app**: share a download link or a magnet from your browser, pick the console, and it downloads into that console's folder — or add it as a source.
- **Reorder the queue**: waiting downloads show their place and can be moved up and down (▲ ▼, or **Y** to put one first).
- **Keep free space** (*Settings*): choose how much space must stay free (1 to 50 GB). No download starts below that, and a running one stops before the storage is full, with a notification.
- **Reserve addresses for downloads**: when a file cannot be fetched from its source, the source's reserve addresses are tried too (2.0 used them only for scanning).

### Library
- **Saved views**: save your filters under a name (★ next to the result count) and switch to them from the *View* filter. *Library tools → Collections → Shortcut* puts a shortcut in the console's folder, so ES-DE opens Dogmatix+ on exactly that view.
- **Favourites from ES-DE** (*Library tools*): every game you starred in ES-DE gets a star here too.
- **Statistics** (*Library tools*): downloads per month, your top consoles, and how many new games your sources brought each week.
- **RomM collections** (*Collections → From RomM / To RomM*): bring your RomM collections into the app or send yours to the server. RomM's favourites become stars.
- **DAT from Redump** (*DAT check → a console → From Redump*): the newest Redump DAT for disc systems, fetched without leaving the app.

### Settings
- **Automatic backup**: once a week, while charging, a backup is written to a folder you choose; the newest five are kept. *Back up now* makes one straight away.

### Fixed
- Importing a large DAT (Redump PlayStation, 10,900 games) took minutes; it now takes seconds.
- The BIOS check no longer counts a PlayStation 1 BIOS as the PlayStation 2 BIOS.
- The second screen now uses the app's language.

### Good to know
- Updating from 2.0.0 keeps everything; there is no database change.
- Tested on an emulator against a local test server: sharing links, the queue order, the free-space guard, reserve addresses, the BIOS check, IPS patching, Redump, saved views and shortcuts, ES-DE favourites, statistics, the second screen (on a simulated second display) and automatic backups.
- **Not tested against a real RomM server**: the collections sync was checked against RomM's source code, not run against a server. Also not tried: a real dual-screen device and real BIOS dumps (the checksums come from libretro's list).
