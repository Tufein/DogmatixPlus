**Dogmatix+ 2.5.0** — ready-to-play checks, smart collections, personal profiles and safer file management.

- Run **Ready to play?** from a game page: check readable files, disc references, relevant BIOS and installed emulators. Follow the console setup steps, save the emulator choice and test a launch.
- Create **smart collections** with console, language-tag, genre, year and played-status rules. Results update from the indexed library and active profile. Genre/year need cached metadata; played status comes from the profile's action history. Convert a smart collection back to a manual one while keeping its current games.
- Set an **offline collection limit in GB**, preview the missing downloads and configure free-space reserves. Existing files, queued games, extraction space and shared membership count towards limits. Internal storage and SD-card volumes have separate free-space budgets. Lowering a limit never deletes games; unknown source sizes wait when a collection has a quota.
- Review **bulk version upgrades** before starting: compare current/offered versions and estimate extra download, extraction and recovery space. Profile restrictions and fixed versions are respected. Old files go to recovery only after the completed replacement passes its applicable checks.
- Each **personal profile** has separate favourites, language/version rules, emulator choices and action history. Existing favourites belong to the general profile. Backups carry favourites and preferences for all profiles plus emulator choices, and remap smart/offline collection settings by name when collection IDs differ.
- Failed action-history rows offer **contextual help** with relevant settings and a retry when one is available.
- File-explorer removal defaults to **verified recovery copies**, including nested folders and same-named files. Restore through Trash and recovery; permanent deletion is an explicit separate option. Empty source folders remain to avoid removing files created by another app during the operation.
- New text is translated into all seven supported languages. Dialogs support controller cancellation and scrolling.
- Android build **37**, database version **14**, established application ID and release signing certificate. The database migration retains existing favourites; recovery journals from 2.4.0 remain readable.

Public versions continue **2.4.0 → 2.5.0**, as a regular release. Install the signed release APK over 2.4.0 to keep application data.

Space totals are estimates when providers do not report sizes or available space. Recovery copies use storage until purged. Closing the app before a pending version replacement completes keeps the old files. An emulator opening is a launch test, not proof that every game runs on every core; real emulators, removable storage and external RomM/WebDAV services still require device-specific testing.
