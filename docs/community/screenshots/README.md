# Package-record screen captures

Captured on 11 October 2026 from the actual 2.9.0 candidate UI on an isolated Android 13 ARM emulator. These are not AYN Thor photographs or physical-device test results. No game folder is configured; the screen shows its empty state, without ROM artwork or personal data.

- [Landscape capture](package-records-android13-landscape.png): English, 1920 × 1080, 320 dpi, normal system text size.
- [Portrait with large text](package-records-android13-portrait-large-text.png): English, 1080 × 1920, 320 dpi, 160% system text size.
- [French with large text](package-records-android13-french-large-text.png): French, 1080 × 1920, 320 dpi, 160% system text size.

The production and test APKs share this UI. Their app data and signing keys are separate. These captures show the test-app version label.

The public 2.9.0 APKs and updates have since passed the [release acceptance checks](../../quality/v2.9.0-acceptance.md).
