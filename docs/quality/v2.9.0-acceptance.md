# 2.9.0 acceptance

Candidate under verification on 11 October 2026. Target Android build 41, database 15; no new public release is asserted by this record until publication checks finish.

## Evidence recorded so far

- 1,486 unit tests passed with zero failures/errors and two existing skips, including five new strict-format tests. Seven release-policy tests passed.
- All 193 Android integration/UI tests passed on isolated Android 13 and Android 15 ARM emulators. Eleven new package-transfer integration cases cover multi-root registration, corrupt receipts, same-size byte changes, provider read failures, missing/wrong roots, source identity, restrictions, stale profile actions, readback, idempotent repeat and private-write rollback.
- The package screen test at 160% text size passed in Android 13 landscape and Android 15 portrait: the empty state enables import, the preview requires confirmation, controller B cancels without writing, and explicit confirmation commits verified records. The final count-label and scrollable-text polish is undergoing a targeted repeat.
- The large-library harness passed with 10,000 and 50,000 synthetic rows, two tags per row and a 5,000-game collection. Matching 2,000 packages used ten SELECTs and preserved all source tags. The old 50k per-row tag lookup took 11,317 ms; 56 bounded tag queries took a median 279 ms (three samples). This supports removing that database bottleneck, not a claim about total UI frame rate or Thor speed.
- Debug, instrumentation and signed production builds passed; the production signer matches public 2.8.0 (`e0e4eaeaf92e4d7a68ef620b021598f0bcbb9f9399e2bdcf18c8297077bedc46`). Lint passed with no unfiltered errors. Existing baseline issues remain; final polished reports are pending.
- The signed local production candidate installed over the actual public 2.8.0/build 40 and started cleanly. Custom/disabled sources, profiles/preferences, favorites, collections/items, history, save-backup bytes, journal bytes, package receipt bytes and their tracking marker were retained; database version stayed 15. Public-asset repeats remain pending.
