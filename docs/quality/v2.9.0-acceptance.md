# 2.9.0 acceptance

Verified on 11 October 2026. [Public release 2.9.0](https://github.com/Tufein/DogmatixPlus/releases/tag/v2.9.0), Android build 41, database 15. The release tag and both published APKs match source commit `0b73bd03f548ccb8a7565b583b19f62c36791012`. The machine-readable [verification record](v2.9.0-verification.json) contains asset checksums, signing identities, CI and upgrade results.

## Software and build checks

- 1,486 unit cases: 1,484 passed, no failures/errors and two existing skips. Five new strict-format cases are included. All seven release-policy tests passed.
- All 194 Android integration/UI tests passed on isolated Android 13 and Android 15 ARM emulators, and on Android 15 x86_64 in [source CI](https://github.com/Tufein/DogmatixPlus/actions/runs/38135979900) and [the release pipeline](https://github.com/Tufein/DogmatixPlus/actions/runs/38136667097). Eleven new package-transfer cases cover multi-root registration, corrupt records, same-size byte changes, provider read failures, missing/wrong roots, source identity, restrictions, stale profile actions, readback, idempotent repeat and private-write rollback.
- At 160% text size, the package screen passed preview/confirmation, controller B cancellation without writes and explicit restore in Android 13 landscape and Android 15 portrait. A narrow French navigation test checks complete rendered labels and button activation. [Actual UI captures](../community/screenshots/README.md) identify their emulator setup; no physical-controller or screen-reader claim is made.
- The large-library harness passed for 10,000/50,000 synthetic rows, two tags per row and 5,000 collection members. Matching 2,000 packages used ten SELECTs while retaining every source's tags. The old 50k per-row tag lookup took 11,317 ms; 56 bounded tag queries took a median 279 ms. [Recorded backend timings](large-library-2026-10-11.json) do not establish complete UI frame rate or Thor performance.
- Debug, instrumentation and signed production builds passed. Lint has no unfiltered errors; the local report has 70 warnings and source CI has 74. Existing baseline issues remain.

## Published APK checks

Both actual downloads match the published SHA-256 checksums, expected package names and build 41. Production retains signer `e0e4eaeaf92e4d7a68ef620b021598f0bcbb9f9399e2bdcf18c8297077bedc46`; the test APK retains stable signer `6e01f3ae0a73660bca0910f23af9e85780233f092af3ee1464c954db61fa7a70`.

Each actual public APK installed over its corresponding public 2.8.0/build 40 on an isolated Android 15 ARM emulator and rendered the app without a startup crash. Custom/disabled sources, profiles/preferences, favorites, collections/items, history, save-backup bytes, personal-journal bytes, package receipt bytes and tracking markers were retained. Database version remains 15. These fixtures verify receipt retention, not launching a game from an unavailable fixture root.
