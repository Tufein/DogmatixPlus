# 2.8.0 acceptance

Implementation is based on published 2.7.0 (`cf36f04159322f8df198b1e5f36951de10889076`), Android build 39, database 15. Target: 2.8.0, Android build 40, database 15.

## Checks to record before release

- Unit tests for catalog validation, h5ai parsing, package identities/strict receipts/nested references, journal boundaries/restore merge and save handoff plans.
- Android tests for additive source merges, package receipts after service/process reconstruction, exact SAF child roots, failed/missing storage, recovery preview, note profile isolation/backup retention and stale/conflicting save handoff.
- Full unit suite, lint, debug/release builds and Android instrumentation suite on an isolated Android 15 ARM emulator.
- Production APK signer/package/version/checksum verification, public asset verification and update from the public 2.7.0 APK without loss of personal data.
- Separate public debug APK signing continuity from 2.7.0.

Local checks on 11 October 2026: 1,481 unit tests, zero failures/errors and two existing skips; seven release-policy tests passed. Debug, instrumentation and signed release builds passed. Android Lint passed with zero unfiltered errors and 70 warnings; the existing baseline remains in place. Production identity is `com.tufein.dogmatixplus`, version 2.8.0/build 40, with the same certificate as 2.7.0 (`e0e4eaeaf92e4d7a68ef620b021598f0bcbb9f9399e2bdcf18c8297077bedc46`).

Final Android instrumentation, upgrade preservation and public APK verification are still in progress. Publication requires their actual results and the GitHub checks to pass.

## External source verification

On 10 October 2026, all 23 catalog directories returned HTTP 200 and had parseable HTML file tables, totaling 134 listed files. These counts include demos and utilities; they are not distinct game counts. Canonical publisher links are listed in `app/src/main/assets/romsets.json`. Source listings and their dated verification record are retained with the local release artifacts. No commercial ROM libraries are bundled or implied.

## Required before the wider Reddit launch

Actual handheld/controller, physical SD-card disconnect/reconnect and live RomM/WebDAV interoperability checks remain required. Record versions and hardware in the [roadmap](../ROADMAP.md).
