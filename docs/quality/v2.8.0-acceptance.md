# 2.8.0 acceptance

Verified on 11 October 2026. Published source: `1ab62e641158f3f68a7bc6ac880528cd5ac09e42`. The regular [2.8.0 release](https://github.com/Tufein/DogmatixPlus/releases/tag/v2.8.0) is the latest public release: Android build 40, database 15, updating published 2.7.0/build 39.

## Recorded checks

- 1,481 unit tests: zero failures/errors, two existing skips. Seven release-policy tests passed.
- All 180 Android integration/UI tests passed with zero skips on a fresh isolated Android 15 ARM emulator and on the GitHub Android 15 x86_64 emulator. This includes source merges, receipt reconstruction/corruption/root changes and verified moves, storage holds after service restart, explicit cancellation, recovery previews, journal backup/profile isolation, actual document-result grants, handoff conflicts/hash verification and stale profile actions.
- Debug, instrumentation and signed release builds passed. Android Lint passed with zero unfiltered errors: 70 local warnings, 74 in CI. The existing baseline remains in place; this does not claim all historic baseline issues were removed.
- [Checks on the merged source](https://github.com/Tufein/DogmatixPlus/actions/runs/38091632383) and the [signed release workflow](https://github.com/Tufein/DogmatixPlus/actions/runs/38091632459) passed. The release workflow runs the complete Android suite again before publication.
- Public APK downloads match GitHub asset digests and the attached SHA256SUMS. The release tag and embedded release metadata match the source commit and version 2.8.0/build 40.
- Production signer matches 2.7.0: `e0e4eaeaf92e4d7a68ef620b021598f0bcbb9f9399e2bdcf18c8297077bedc46`. The debug APK retains the separate stable test signer: `6e01f3ae0a73660bca0910f23af9e85780233f092af3ee1464c954db61fa7a70`.
- The actual public production APK installed over public 2.7.0 and started cleanly. Custom/disabled sources, profiles/preferences, favorites, collections/items, download history, save-backup bytes and a pre-existing journal fixture file were retained. Database version stayed at 15.
- The actual public debug APK installed over public 2.7.0-debug and started cleanly. The private data marker and personal preference values were retained. The internal version-seen marker was checked separately: it may remain at 39 until the update dialog is acknowledged, then advance to 40.

Local public-asset, checksum, signer, test and upgrade records are retained alongside the downloaded APKs. Public-upgrade fixtures use the current installation's Android private-data label, and the UI check acknowledges Android's standard full-screen welcome prompt when present. Earlier local runs using an inherited emulator encountered foreground interference from an unrelated installed launcher; the final ARM run above used a fresh single-display emulator. No passing result is inferred from those failed runs.

## External source verification

On 10 October 2026, all 23 catalog directories returned HTTP 200 and had parseable HTML file tables, totaling 134 listed files. These counts include demos and utilities; they are not distinct game counts. Canonical publisher links are listed in `app/src/main/assets/romsets.json`. Source listings and their dated verification record are retained with the local release artifacts. No commercial ROM libraries are bundled or implied.
