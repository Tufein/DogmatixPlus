# 3.0.0 acceptance

Recorded on 12 October 2026 for Android build 42, database 15. This record lists only what was run. It is not a launch sign-off.

## Software checks that were run

- 1,529 JVM unit cases: 1,527 passed, no failures or errors, two existing skips. New cases cover Up next ordering and states, the For you ranking and its reasons, the sanitized problem report (paths, document ids, host names and keys removed) and the Library repair rules (empty files, loose files outside console folders, unread sheets).
- The source CI "Test" workflow passed on commit `4c999206e24235e69bf87b0800a9c7a1bd2027e3`: unit tests, lint against the existing baseline, the debug build and the Android integration tests on the CI emulator. The three new screens have no dedicated emulator UI tests; they are covered by unit tests of their logic and by the existing navigation and search-index tests.
- An independent read-through of the diff before release found and fixed these problems: Library repair could offer to move another app's partial downloads or empty files outside the console folders; it could call a file empty when a storage provider reports no size; it compared a file against the largest listed size instead of the smallest; it could judge a playlist while a disc sheet in its folder had not been read; and suggestions or the Home shelf could show a game a restricted profile hides by tag. Each was changed and, where it is pure logic, tested.

## Not checked

- No physical AYN Thor or any other handheld was used. The controller, both displays, sleep and resume, SD-card interruption and accessibility checks in the [launch matrix](community-launch-matrix.md) have no recorded results.
- No RomM or WebDAV server was used.
- The three new screens were not driven by a person on an emulator or device. Controller focus order, large-text layout and the wording of the translations (written without a native review) are unverified.
- Library repair was not run against a real library on removable storage; its file operations rely on the same trash and verified-copy code as other removals, which have their own tests.
- The signed release update from 2.9.0 is checked by the release pipeline, not by hand; no installed 2.9.0 data was upgraded here.

The Reddit launch draft has not been posted.
