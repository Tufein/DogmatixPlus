# 2.4.0 acceptance

## Source and release identity

Based on published 2.3.0 (22bcddac93641d1aaa364ecce95e511fa2f2a79f) and the completed Claude feature branch (02e57096141084dbee74049ad47fa359f8e2419e), with review fixes for restore, history persistence, version pins, shared disc planning and explicit emulator variants.

Public version 2.4.0, Android build 36, package com.tufein.dogmatixplus, database version 13. The consecutive numbering policy accepts this release after 2.3.0/build 35. Existing 8.x APKs keep their historical internal names; build numbers identify updates.

## Required verification

- Full JVM test suite and release policy tests.
- Debug and Android test APKs; Android integration suite including real storage-provider operations, queue/HTTP behavior, release metadata, action-log persistence, partial restore and cross-UID emulator-intent read grants.
- Lint against the historical baseline, signed release build and pinned signing certificate.
- Install as an update over the published signed 2.3.0 APK.
- Open emulator settings, version preferences and action history; exercise saving/reloading preferences and search/filter/back navigation. Check narrow portrait with enlarged text and landscape.
- GitHub CI before merge/publication; published release metadata, asset digests and tag/source identity after publication.

## Local results

- JVM tests: **1,344 tests, 0 failures, 0 errors, 2 skips**. The skips require a full Redump DAT fixture and live RomM credentials.
- Debug and Android-test APKs built successfully after the final archive-companion and playlist-reference guards.
- `lintDebug`: **0 errors**, with the repository's existing warning baseline unchanged.
- Signed `assembleRelease`: successful. The APK reports package `com.tufein.dogmatixplus`, version `2.4.0`, build `36`; APK signature verification passed with certificate SHA-256 `e0e4eaeaf92e4d7a68ef620b021598f0bcbb9f9399e2bdcf18c8297077bedc46`.
- Local isolated emulator boot was unavailable because the AVD snapshot exited before ADB became ready. The Android instrumentation suite therefore remains a GitHub CI gate before merge and publication.

## Limits

Physical SD-card removal, actual emulator execution/controller hardware and two live RomM/WebDAV clients still require device acceptance. Tests against a probe activity prove URI grants and intent data; they do not certify every emulator build. Action history is global; a download-again action checks the active profile before queueing. Recovery copies retain space until purged.
